## 🚀 Featured Projects

### [DevContext](https://github.com/zhytkovd/devcontext)

AI-powered GitHub codebase assistant that answers questions using **live repository source code** and shows the files the model used to generate each answer.

- Built with **OpenAI Responses API + Model Context Protocol (MCP)**
- Serverless backend using **AWS Lambda, API Gateway, and AWS CDK**
- **React frontend** hosted on AWS Amplify
- Displays model tool-call traces and cited source files
- Supports multi-turn repository conversations
- Automated **CI/CD deployments**
- Costs roughly **$0.01 per query**

[Live Demo](https://main.d3gcrotthe39k2.amplifyapp.com) · [Repository](https://github.com/zhytkovd/devcontext)

### [Limari.org](https://limari.org/)

Full-stack e-commerce platform for a local clothing business, designed as a custom alternative to their existing storefront.

- Built REST APIs for products, carts, orders, and payments
- Implemented **JWT authentication and role-based authorization**
- Designed a PostgreSQL data layer with **Prisma**
- Dockerized development environment

**Tech:** `TypeScript` `NestJS` `PostgreSQL` `Prisma` `Docker`
